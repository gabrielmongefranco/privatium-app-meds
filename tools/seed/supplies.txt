# Summary: Syringes and needles of the starter catalog, by family. The build script makes
#          one entry for each volume, gauge and length of a family.
# Format: five parts on a line, with " | " between them:
#           code | name | volumes | gauges | lengths
#         code     Two digits that stay with the family for good. They are part of the
#                  id of every entry, so a code is never changed or used for another
#                  family. Two lines may share a code when they share a name.
#         name     The name of the item, without its size.
#         volumes  In millilitres, with commas between them. A dash means none.
#         gauges   One gauge, or a range such as 27-34. A dash means none.
#         lengths  With commas between them. A length in inches is written as on the
#                  box, such as 1/2 or 1 1/2. A length in millimetres ends in mm.
#                  A dash means none.
# Notes: See README file for documentation and full license information.
#        The entries name sizes only, not brands. Not every size is sold by every maker.
#
